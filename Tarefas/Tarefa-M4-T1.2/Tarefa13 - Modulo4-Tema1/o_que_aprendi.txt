Nesta tarefa aprendi a usar o Ansible para automatizar tarefas em
sistemas Linux, usando um inventário, um playbook e um Makefile.

Passo 4 - ansible -m ping
O módulo ping do Ansible não é o ping de rede normal. Ele conecta-se
via SSH ao host e verifica se consegue autenticar-se e se o Python
está disponível. Se correr bem, o host responde com "pong". No nosso
caso o host era o localhost, por isso funcionou sempre.

Passo 6 - Nova task df -h
O nome do grupo é definido pela opção "hosts:" no playbook.
No nosso caso "hosts: all" significa que as tasks são executadas em
todos os hosts do inventory.ini. Adicionar o "df -h" foi simples e
mostrou como é fácil adicionar novos comandos a um playbook existente.
